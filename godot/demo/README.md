# Scene timelines

These are fixed snapshots. The JavaScript mockup made them at commit
`1e6531a128cdf339385c0ef5df27cf8d3d3eceab`, the last commit before the mockup was removed. The mockup
is in the git history, in `tools/mockup-2d/`. No tool makes these files again. Edit them by hand if
a scene must change, and keep them valid against `schema/event.schema.json`.

Each `.json` file is one scene: schema v1 events with times, and the clicks and keys of the person.
The data is made up. It holds no real session. The scene menu of the client lists every `.json` file in this folder.
